# PowerShell from Zero

A practical learning journey into PowerShell, starting from the fundamentals and gradually moving toward automation, Windows administration, and cybersecurity use cases.

This repository contains the examples, exercises, and practice tasks from the **"PowerShell from Zero"** article series.

The goal of this project is not to memorize commands, but to understand how PowerShell works:

* How cmdlets are structured
* How to discover commands using built-in documentation
* How objects and properties work
* How the pipeline connects commands together
* How PowerShell can be used for system administration and security tasks

## 📚 Series Progress

### Part 1 — Understanding PowerShell Before Writing Scripts

Topics covered:

* Introduction to PowerShell
* PowerShell vs CMD
* Cmdlets and Verb-Noun naming
* `Get-Command`
* `Get-Help`
* `Get-Member`
* Understanding objects

### Part 2 — Understanding the Pipeline

Topics covered:

* The pipeline (`|`)
* Passing objects between cmdlets
* Working with multiple commands together
* Introduction to object manipulation
